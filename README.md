# Project 1 — Business Insights Dashboard Superstore 

**Goal:**  Analyze retail sales data and deliver an interactive Tableau dashboard
**Tools:** Spreadsheets Excel for cleaning · Tableau for visualization

## Data
- Source: Kaggle — Superstore Dataset (https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- Files :
  - `data/raw/` —".\data\raw\Sample - Superstore.csv"
  - `data/processed/` ".\data\processed\Sample - Superstore_Clean.csv"
  - `spreadsheets/` ".\data\processed\Sample - Superstore_Clean.csv"

## Steps
1. Cleaned raw Kaggle CSV in Excel (standardized dates, fixed categories, created Profit Margin, Year, Month, Quarter).  
2. Exported processed file to CSV.
3. Built Tableau dashboard
4. Added KPI cards (Sales, Profit, Profit Margin,)
5. Published to Tableau Public. 
6. Added insights for stakeholders .
